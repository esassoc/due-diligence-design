Card

Surface container with an optional header (icon, title, meta pairs, actions), body, and footer. Variants, header tints, and padding scales.

Inherited .astro import EsaCard from '@esa/ecology/esa-card.astro';

Preview

Meta pairs

Each entry in meta is a { label, value } pair: the label is the field's name in the record, the value is what is stored there. Both parts are required, so the header can carry several facts without the reader having to work out how they relate.

A pair identifies the record: which project, which permit, which period. A figure the card exists to report is a stat, so put it in an esa-stat in the body, where it reads at stat scale.

Actions & footer

The actions slot sits at the right of the header; the footer slot renders a bottom band.

API

PropTypeDefaultDescription
title string — Header title. Presence (or meta, or a header/actions slot) renders the header band.
meta EsaMetaPair[] — Identifying facts about the record, as {label, value} pairs. Renders as a definition list under the title, each label beside its value. Both parts are required. A period pair states its calendar: "Calendar Q3 2026", not "Q3".
subtitle string — Deprecated 2026-08-16 in favour of meta; still renders. A free-text line cannot name what its facts are.
icon string — Lucide icon name shown left of the title.
variant 'default' | 'outlined' | 'elevated' | 'filled' 'default' Surface treatment: bordered, shadowed, or sunken.
headerVariant 'default' | 'primary' | 'muted' 'default' Header band tint.
padding 'none' | 'compact' | 'default' | 'spacious' 'default' Body and header padding scale.

Slots

PropTypeDefaultDescription
default slot — Card body content.
header slot — Replaces the title block entirely with custom markup.
actions slot — Right-aligned controls in the header band.
footer slot — Bottom band below the body.

Accessibility

  • Renders a plain <div> — add role/landmarks at the call site if the card is interactive or a region.
  • The title is an <h3>; keep heading order sensible within the surrounding page.
  • The header icon is aria-hidden — it decorates the title, not replaces it.
